# Aptitude Forge

A personal, AI-assisted aptitude practice app for GATE CSE and SSC CGL. Questions are generated by
rules, solved independently by a separate solver, and validated before you ever see them. AI (Gemini)
is optional, runs only when you click a button, and its final answers are checked against ours.

## What it does
- 6 chapters, 34 question types: percentages, ratios and proportion, profit and loss, time and work,
  averages and mixtures, simple and compound interest.
- Every wrong option comes from a real mistake and carries an explanation and a tag.
- Step-by-step solutions, answer history, progress dashboard with weak-topic detection.
- Optional AI: "Explain differently" on a question and "Study advice" on the dashboard.

## Stack
React + TypeScript + Vite + Tailwind | Python + FastAPI + Pydantic | MongoDB (Atlas)

## Setup
Backend (Python 3.13):
```bash
cd backend
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.lock.txt
cp .env.example .env        # then fill in MONGO_URI and, optionally, GEMINI_API_KEY and GEMINI_MODEL
python -m app.tools.create_indexes
```
Frontend (Node 22):
```bash
cd frontend
npm install
```

## Run
```bash
# terminal 1
cd backend && source .venv/bin/activate && uvicorn app.main:app --reload
# terminal 2
cd frontend && npm run dev          # http://localhost:5173
```

## Test
```bash
cd backend && pytest -q             # uses an in-memory Mongo and a fake Gemini, no secrets needed
cd frontend && npm run build        # type-check
```

## Useful tools (run from backend/)
- `python -m app.tools.quality_report` : how many wrong options are real mistakes, and the size of each question pool
- `python -m app.tools.review_sheet` : writes review_sheet.md with sample questions to read through

## Layout
- `backend/app/engine`: generators (one file per chapter), solver, validator, wording variants
- `backend/app/api`, `backend/app/services`: HTTP routes, practice sessions, analytics, AI
- `frontend/src`: setup screen, practice screen, dashboard

## Notes
- Personal use: no login, all statistics are global.
- Rule for generators: only ever APPEND to a `traps` list. Mistake tags are positions in that list.
- The marks and timings in the exam profiles were written from memory. Check them against the
  latest official notifications.
- Never commit `.env`. It holds the database password and the Gemini key.
